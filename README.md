# Letter Rush

등불 축제 날, 우편 증기 기관차에서 쏟아진 초대장을 **3분** 안에 모아 축제 광장까지 달려가는 3D 러너 게임입니다 (three.js, 브라우저에서 바로 실행).

## 실행

빌드 과정이 없습니다. 정적 서버로 폴더를 열면 됩니다 (`index.html`을 더블클릭하면 모듈 로딩이 막힐 수 있어요).

```bash
npx serve .        # 또는: python3 -m http.server
```

GitHub Pages(Settings → Pages → Branch: `main`, 폴더 `/`)로 켜면 `https://<사용자명>.github.io/subway-surfers/` 에서 바로 플레이할 수 있습니다.

## 게임 내용

- **스토리**: 처음 출발하면 5장짜리 스토리가 나오고, 시작 화면의 "스토리" 버튼으로 다시 볼 수 있습니다.
- **아이템**: 회오리 가방(편지 끌어오기) · 별빛 망토(장애물 통과) · 특급 우표(편지 점수 2배) · 따뜻한 코코아(목숨 +1)
- **보스**: 남은 시간 50초쯤 도둑 까마귀 "까망"이 나타납니다. 먹물 폭탄과 깃털 장벽을 피하면서 선로 위 등불 폭죽을 주우면 까망에게 발사되고, 6번 맞히면 격파(+1500점)입니다.
- **캐릭터**: 민트(점수 +10%) · 써니(아이템 시간 +40%) · 코코(점프가 더 높고 김) · 레오(부딪혀도 덜 느려지고 오래 버팀)
- **맵**: 노을 도시 · 네온 밤 · 사막 협곡 · 눈 덮인 산 · 벚꽃 공원 (맵마다 배경음악이 다름, 오른쪽 위 ♪ 버튼으로 소리 조절)
- **점수**: 달린 거리 + 편지 1통 50점 + 보스 격파 1500점 + 완주 시 남은 목숨당 500점
- **순위**: 누구나 로그인 없이 TOP 10을 볼 수 있습니다. 아래 "모두의 순위" 참고.

## 모두의 순위

계정 없이 누구나 보고 등록할 수 있습니다. 게임이 끝나면 닉네임만 넣고 **등록**을 누르면 바로 TOP 10에 반영됩니다.

- **저장소**: 가입이 필요 없는 무료 JSON 저장 서비스(jsonblob.com)를 씁니다. 주소는 `leaderboard-config.json`에 있고, 처음 한 번 `Leaderboard setup` 워크플로가 만듭니다.
- **백업과 복구**: `Leaderboard backup` 워크플로가 30분마다 순위를 `leaderboard.json`에 백업합니다. 형식이 틀리거나 확인값이 맞지 않는 기록은 버리고, 누가 저장소를 지워도 백업으로 되돌립니다. 저장 서비스에 연결되지 않으면 게임은 백업 파일을 보여줍니다.
- **기기 구분**: 같은 브라우저에서는 최고 기록 하나만 남습니다(상위 100개 저장).

누구나 쓸 수 있는 공개 저장소라서, 마음먹고 조작하는 것까지 완전히 막지는 못합니다. 이상한 기록은 `leaderboard.json`에서 그 줄을 지운 뒤 `Leaderboard backup` 워크플로를 실행하면 됩니다.
